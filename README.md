# Jhonty Hub (JH) — Shopify Online Store 2.0 Theme

An ultra-premium, high-converting **Shopify Online Store 2.0** theme built for **Jhonty Hub (JH)**, Hyderabad's premier men's streetwear and luxe fashion brand. 

Combines high-volume multi-category retail architecture (inspired by Lifestyle Stores & Zara Men) with an obsidian/champagne-gold luxury aesthetic, $3\text{D}$ card tilt physics, interactive ambient lighting, and instant **Dark / Light theme switching**.

---

## 🌟 Key Features

1. **Bespoke JH Vector Brand Lockup**:
   - High-precision geometric gold hexagonal crest with interlocking brushed-gold **'J'** and platinum chrome **'H'**.
   - Luxury serif branding: **JHONTY HUB** with subtitle `STREETWEAR & LUXE ATELIER • HYD`.
2. **Interactive Dark / Light Mode Switch**:
   - One-click header toggle pill with active Sun ☀️ / Moon 🌙 icons.
   - Smooth CSS variable transition between *Obsidian Noir* and *Alabaster Editorial* modes.
   - Persistent theme state using `localStorage`.
3. **High-Volume Multi-Category Navigation**:
   - Sticky frosted glass header with central live search bar.
   - 8-department category ribbon (Oversized Tees, Korean Shirts, Baggy Denim, Parachute Cargos, Chunky Kicks, Varsity Jackets, Jhonty Scents, Hyderabad Flagships).
   - Category Story Bubbles with circular micro-zoom imagery.
4. **Rich Streetwear Product Catalog**:
   - Heavyweight 280–320 GSM graphic drop-shoulder tees, liquid satin Cuban collar shirts, Japanese skater wide-leg denim, and chunky street runners.
   - Native Indian Rupee (`₹`) pricing with strike-through MRP and discount tags.
   - Quick size swatch selectors (`S`, `M`, `L`, `XL`, waist sizes, UK shoe sizes).
5. **Hyderabad Flagship Stores Integration**:
   - Dedicated physical store spotlight for **Kukatpally Flagship**, **Madhapur Studio**, and **LB Nagar Branch** with direct WhatsApp Concierge (`+91 91606 63888`).
6. **Velvet Vault (Slide-Out Cart Drawer)**:
   - Real-time subtotal computation, free express delivery unlocked progress bar, and instant checkout link.
7. **Interactive Micro-Effects**:
   - Ambient gold spotlight following the cursor across the canvas.
   - Dynamic $3\text{D}$ perspective tilt on product cards and promo banners.

## 📦 Theme Package & Files

* **`lifestyle-retail-theme.zip`** (or **`apex-theme.zip`**): Packaged, verified Shopify OS 2.0 theme ready for direct drag-and-drop upload in Shopify Admin.
* **`preview.html`**: Standalone, interactive HTML preview testable in any browser offline.
* **`assets/`**:
  * `base.css`: Complete styling with CSS custom properties for dark/light theming, typography, and layout.
  * `theme.js`: Cart drawer management, theme toggle handler, 3D card tilt listener, and ambient lighting.
  * `logo.svg` / `logo.png`: Native luxury brand assets.
* **`sections/`**: Modular Online Store 2.0 Liquid sections (`header.liquid`, `footer.liquid`, `hero-carousel.liquid`, `promo-grid.liquid`, `featured-collection.liquid`, `category-bubbles.liquid`, `trust-badges.liquid`, etc.).
* **`snippets/`**: Reusable Liquid components (`icon-logo.liquid`, `cart-drawer.liquid`, `product-card.liquid`, `price.liquid`, etc.).
* **`templates/`**: Full JSON template system (`index.json`, `product.json`, `collection.json`, `cart.json`, `page.json`, `404.json`).

---

## 🚀 How to Install on Shopify

1. Go to your **Shopify Admin** &rarr; **Online Store** &rarr; **Themes**.
2. In the **Theme library** section, click **Add theme** &rarr; **Upload zip file**.
3. Select `lifestyle-retail-theme.zip`.
4. Click **Publish** or customize using Shopify's native Theme Customizer.
